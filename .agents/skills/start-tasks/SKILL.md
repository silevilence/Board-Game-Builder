# 开始执行任务

用法：`/start-tasks M0任务`。以调用时指定的范围为限，遵守项目 AGENTS.md，以 ROADMAP.md 为需求与验收依据。

1. 开始实施前，先读取相关需求、检查环境与依赖，集中确认所有可预见的待定事项并完成必要权限申请；已有确认不重复询问，无待定事项直接开始。执行中不依赖用户及时回复；遇到新发现且必须确认或授权的阻塞，暂停相关工作并继续可独立推进的任务，不擅自决定或越权。
2. 根据依赖与风险自行安排合理的任务顺序，完成指定范围内的全部任务。
3. 每项任务完成后，只做必要验证、快速审核与阻塞项修复；完整整体审核留到所有任务完成后。
4. 每项任务验收通过后，在 ROADMAP.md 原地勾选对应条目，不搬移条目；将该任务实现与勾选一并本地提交，不推送，不混入无关改动。
5. 全部任务完成后，进行完整的整体审核、修复与回归验证，补充本地提交；简要报告完成情况、验证结果及剩余阻塞，未通过验收的任务不勾选。
