# 空当接龙

单人、离线，使用 Kenney Playing Cards Pack 原始 PNG。资源许可见 `assets/License.txt`（CC0）。

## 开始

开发环境：`dotnet run --project src/Player -- gui samples/freecell`。
独立导出：双击 `Play.exe` 即进入经典牌桌，依次点击右下角「洗牌」「发出 52 张明牌」，或按两次 Enter。种子相同得到相同牌局；本引擎的种子不对应微软空当接龙牌局编号，也不保证每个随机牌局可解。

## 经典桌面（1.2.0）

绿色牌桌、灰色菜单和状态栏，左上四个空当，右上四个花色收牌位，下方八列牌。Kenney 原始牌面配合轻阴影，选中的牌和提示目标以金色边框标记；拖动时显示实际牌或牌组。

窗口尺寸变化时自动适应整桌；手动滚轮缩放或平移后，通过「查看 → 适应窗口」恢复。可用动作列表收进「查看 → 显示 / 隐藏可用动作」；游戏菜单提供新局、重开、开局设置和结束对局；查看菜单提供撤销与提示；「帮助 → 玩法与操作」可随时查看说明。模块加载与工具栏入口在文件菜单，种子和席位在开局设置（F3）中调整，取消不改变当前对局。

标题、帮助和动作栏默认状态在 `player.json` 中配置；`viewTheme=1` 只控制经典桌面视觉。`gui samples/freecell --shell tools` 可保留加载工具栏并等待开局，`--shell game` 直接进入游戏，两者不影响规则。

## 玩法

- 8 列明牌，前 4 列各 7 张，后 4 列各 6 张。点选牌，再点目标牌／区域即可移动；也可拖动或选择右侧对应动作。
- 下方列按红黑交替、点数递减叠放；空列可以放任意牌或合法连续牌组。
- 左上 4 个空当各放 1 张牌。右上 4 个收牌区按同花色 A、2…K 收牌；已收牌不退回（撤销最后一次收牌除外）。
- 拖动连续牌组的第一张牌；最大张数为 `(空当数+1)×2^可用空列数`，目标本身为空列时不计入可用空列数。
- 「撤销上一步」只撤销最近一次搬牌，可撤销整组搬牌；不支持连续撤销或胜利后的撤销。收齐 52 张即胜利；没有好走法时可以撤销、重开或认输。
- 滚轮缩放；区域高度随牌列增长。不会自动收牌，以免提前收牌破坏你的策略。

## 快捷操作（1.1.0）

| 操作 | 效果 |
| --- | --- |
| 左键点牌，再点目标 | 移动单张或选中牌起始的合法连续牌组；点击目标牌等同点击所在列 |
| 再点已选牌 / Esc / 点桌面空白 | 取消选择 |
| 双击可移动的单张牌 | 优先移入对应收牌区；不能收牌时，将列底牌放入第一个空当。无合法位置时保持原局面 |
| 按住牌上的右键 | 临时完整显示该张牌，便于辨认被遮挡的花色；松开或失焦恢复，不产生移牌 |
| 中键拖动 / 桌面空白处右键拖动 | 平移桌面，避免与右键看牌冲突 |
| 1～8（含小键盘） | 无选择时选中对应列底牌；有选择时移到对应列 |
| 0 / 9 | 将所选列底单牌送入第一个空当 / 将所选牌送到收牌区 |
| Ctrl+Z / F10 / U | 撤销上一步，仍仅保存一步历史 |
| H | 高亮一个合法走法并显示说明，不保证最优，也不会代替你出牌 |
| Enter | 执行洗牌／发牌动作；种子输入框内按 Enter 开始该种子的牌局 |
| F2 / F3 / Ctrl+R | 新种子开始 / 打开开局设置 / 使用当前对局的种子重新开始 |

双击优先收牌是本示例的便利规则；经典 Windows 的双击送空当、按住右键看牌可参见 [Windows 2000 操作说明](https://flylib.com/books/en/3.229.1.292/1/)。本轮没有增加自动收牌或多步撤销。

## 作者与验收

编辑器打开此目录的 `module.json`，使用同一规则、资源和 PlaySession；规则修改位于 `rules.lua`。
`dotnet run --project tests/Engine.Tests -c Release -- freecell freecell-shortcuts freecell-modes` 运行规则、布局、输入状态机、快捷动作、种子、回放、模块包与完整胜利路径测试。
CPU 仅优先收牌并最终认输，用于运行时冒烟，不是解算器，不以 CPU 正常退出作为解局证明。

容器使用通用整数表现属性 `viewFanY`、`viewWidth`、`viewHeight`、`viewCardWidth`、`viewCardHeight`；`viewHidden=1` 仅隐藏图形项，不影响投影权限。`viewTheme=1` 选择经典牌桌，`viewSuit=1..4` 标记梅花／方块／红桃／黑桃牌位，`viewHotkey=1..8` 声明列键位。容器显示顺序来自投影的 `contents`，不按实体 ID 排序。主题属性不参与规则判断。

重新导入原始资源（会重建初始 module.json）：`python scripts/import-freecell.py <kenney_playing-cards-pack.zip>`。
