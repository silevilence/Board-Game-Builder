# 六角小队战

在 Player 加载此目录或导出的 game.bgm，选择 p1 为真人开始。
p2 是红队 CPU 队友，p3 是蓝队 CPU 对手；全部设为 CPU 可自动验证。

棋盘使用轴向 q/r 坐标，范围 q=0..4、r=0..3。每席位控制一个单位，
每回合 2 AP；移动至空的相邻格或攻击相邻敌人各花费 1 AP。
攻击后点“结算掷骰与伤害”：骰子 1..3 造成 1 点伤害，4..6 造成 2 点。
HP 为零的单位退出战斗但仍可结束自己的席位回合。

消灭敌队获胜；最多 30 个席位回合，达到上限时剩余总 HP 较多的队伍获胜，
相同则平局。获胜队伍的所有席位共享结果。移动、AP 消耗、伤害和胜负均由 Lua 定义。

编辑器可改位置、HP 上限、骰面、席位顺序、阶段和脚本。
配置变化需重开对局；只改规则或 CPU 脚本可在命令边界热重载。
