# 群岛开拓 · Island Settlers

基于卡坦岛概念的 **M3 引擎总体示例**，并非基础版的完整复刻。四个独立席位可由真人或 CPU 控制；默认 p1、p2 真人，p3、p4 CPU。资源来自用户指定的三个 Kenney 包，许可保存在 assets。

资源来源在 `game.start.json` 中配置：`resources.images` 通过 `assets` 下的 `*.png` 加载图片，以文件名去掉扩展名作为资源名；`resources` 将 `player.json` 注册为 `player.presentation`。配置规则见 [运行插件协议](../../docs/runtime-plugins.md)。

## 开始

在 Editor 打开本目录的 game.start.json，或运行：

```powershell
dotnet run --project src/Player -- gui samples/island-settlers
```

启动后直接进入默认热座对局，p1、p2 为真人，p3、p4 为 CPU。游戏 → 开局设置（F3）可逐席位选择真人，其余自动交给 CPU；全选即四人轮流操作。单人请选择「单人 + CPU」并保留一名真人。确认后开新局，取消保留当前对局。每次交接需接手玩家确认，私有发展牌只在自己的投影中显示。同屏分视角也可使用，但不能阻止旁观屏幕。

文件菜单可加载模块或显示工具栏；命令行 `gui samples/island-settlers --shell tools` 可直接进入工具界面。标题、帮助和动作栏默认状态在 `player.json` 中配置，与棋盘主题独立。

双击交点建村庄／升级、双击道路建路、双击地块移动强盗、双击自己的发展牌使用；也可使用右侧合法动作。滚轮缩放，中键平移。编号与费用在动作中显示。初始化时选择是否开启秘密竞拍。

## 规则与简化

- 19 个六角地块、54 个交点、72 条边。每人按 p1→p4 顺序放置两组免费村庄与道路（两轮顺序相同），开局每种资源 2 张。
- 双骰点数对应地块为所有相邻村庄生产 1、城市生产 2；强盗所在格不生产。7 点移动强盗；本示例不执行弃牌和偷牌。
- 村庄不得紧邻任何建筑；道路须接自己的建筑或未被对手截断的道路；新村庄须接自己的道路。每人最多 15 路、5 村庄、4 城市。
- 道路木1砖1；村庄木砖羊麦各1；城市麦2矿3；发展牌羊麦矿各1。港口统一任意同类资源 3 换 1，不进行玩家间议价。资源数量公开、银行不限库存；发展牌与密封出价隐藏。
- 每回合最多两次建设／交易／买牌／用牌，结束时补给当前最少的一种资源 1（同数按木砖羊麦矿顺序）。这是让示例在有限时长内可玩完的简化机制。
- 发展牌共 24 张：骑士（声望 +1 并移动强盗）、丰收（每种资源 +1）、工匠（木砖各 +2）各 8 张。每回合至多使用一张，允许购买当回合使用；不含基础版的垄断、道路建设和隐藏胜利点卡。
- 村庄 1 分、城市 2 分、每点声望 1 分；任意席位达到 7 分立即结束。最多 12 轮，此后按最高分结算，同分并列。未实现最长道路、最大军队或基础版 10 分胜利。
- 可选秘密竞拍：从第 2 轮起每轮竞拍 1 点声望，以 0～3 麦出价并锁定，只向获胜者收取出价；0／弃权不获奖。同价从 p1 开始逐轮轮换优先席位。所有提交锁定后由 p1 截止、揭示、结算；p1 也可推进收集时钟使缺席者弃权。提交期间不可建设或花掉出价资源。关闭竞拍可独立完成游戏。

规则参考：[CATAN 官方基础规则与问答](https://www.catan.com/faq/basegame)。上述差异是本示例规则，非官方规则。

## 能力覆盖

| 能力 | 示例入口 |
| --- | --- |
| 数据模块、Lua 规则与 CPU、合法动作和原子命令 | 建造、生产、计费、终局全部在 Lua |
| 可复现随机、洗牌、双骰与回放 | 开局牌库洗牌、每回合掷骰、CPU 平局随机 |
| 容器、归属、隐藏投影 | 私有发展牌、牌库、弃牌堆 |
| 六角地图、资源、计数器、移动、翻面 | 六角拓扑以自由布局承载边与交点；强盗移动、建筑／骰子多面 |
| 本地热座／分视角、混合 CPU | Player 席位配置与换座遮蔽 |
| 秘密提交、锁定、截止、揭示、拍卖 | 可选港口声望竞拍 |
| 受限 WASM 组件与命令 | 港口成交次数使用已有 counter 插件；带版本、哈希与权限声明 |
| 编辑、热重载、暂停单步、两种 Play、日志 | 复用 Editor 对本模块的通用作者工作流 |
| 图片导入、卡图切分、打印、TTS | 可在 Editor 对资源／发展牌使用图片和打印工具；本示例不需要 TTS 导入，不声称覆盖其转换语义 |

重建资源、module.json 与 game.start.json：`python scripts/import-island.py E:/silev/Downloads`。规则和 CPU 文件不会被生成器覆盖。

自动验证：`dotnet run --project tests/Engine.Tests -- island`。批量：`dotnet run --project src/Player -- batch samples/island-settlers --count 20 --out artifacts/island-batch`。验收结果见 `docs/validation/island-review.md`。
