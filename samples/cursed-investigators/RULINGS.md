# Sample 实现裁定

2026-10-17 用户确认：交付标准单人、战役及初学者变体；授权为扫描未明确的边界制定确定性裁定。以下是本示例的实施口径，**不是官方补充规则**。明确规则仍以 [扫描转写](RULES.md) 和 [卡牌](CARDS.md) 为准。

## 范围

- 标准单人：三层 3／2／1 个遭遇，全部结算后胜利。
- 战役：首局同标准，第二局 3／3／1；同角色、职业，移除首局已捕获咒物，保留累计声望、观察记录及未使用奖励。第二局按设置规则重置属性和健康，清空骰子及回合状态。
- 初学者：可以选择健康作为完成挑战奖励，适用于以上两种模式。
- 关卡、挑战者：保留原文，不提供启动选项，也不宣称实现。

## 数值、骰子及组合

- 幸运、决心、知识都按格移动；达到顶端不再增加。知识到最低格后继续降低时支付健康，避免低于印刷轨道。健康进入骷髅即失败。
- 骰子点数限制为 1～6；强制减点在 1 截止。主动改点不得越界。
- 每职业能力格最多一颗骰子，一次放置触发一次效果；本回合放入的骰子到下一回合才可取回。知识低于保留数量时新掷数量为零，已保留骰子全部取回，普通骰子总数最多六颗。
- 两对子、对子＋三条、两组三条要求各组点数不同，且不重复使用骰子。
- 阴魂“欺骗”：同点／指定点数／阈值要求增加同条件骰子；序列延长一颗；组合要求另加一颗任意点数；每项最终最多六颗。旧玩具屋的额外费用另付任意一颗骰子，不改变组合要求。
- 奖励骰独立于六颗普通骰子，只能支付挑战；不可改点、重掷或保留，用完或回合结束移除，奖励使用状态不回退。

## 结算与选择

1. 初始掷骰：生成新骰 → 咒灵已揭露的修正按下、中、上顺序 → 咒物修正 → 保留骰子保持／重掷选择 → 形成骰池。各修正仅执行一次，不因重掷结果递归触发。
2. 同点数最大骰、被迫重掷某颗保留骰等同条件选择采用稳定骰子编号；所有点数相同的骰子指修正开始时重复点数组中的全部骰子，统一重掷一次。
3. 完成挑战：支付附加费用及骰子 → 标记挑战完成 → 立即由玩家选属性奖励 → 当前已生效的完成挑战能力 → 揭露新能力并结算一次性效果 → 捕获／遭遇结算。新揭露的能力不追溯刚刚完成的挑战。
4. 第三项咒物挑战后立即获得可使用的捕获奖励并移除咒物效果；击败咒灵后才登记捕获、观察与声望、重置知识和开放下一遭遇。未击败咒灵不算本局／战役完成。
5. 每回合最多一次挑战。遭遇结算后仍结束当前回合，下一遭遇从新的回合开始；重置知识为角色与职业合计的初始格，幸运、决心、健康保留。
6. 回合结束：先完成保留选择 → 按结束条件退回不允许保留的骰子 → 未完成挑战的基础健康损失 → 咒灵下、中、上的结束效果 → 咒物结束效果 → 清空未用骰子。任一步死亡立即终止，后续收益不能复活。
7. 使用忽略效果奖励只阻止使用后本回合的对应效果，不撤销已经发生的改点／扣属性。下回合恢复，已揭露的一次性能力不重新触发。

## 个别卡牌

- 恐怖娃娃：该效果生效的回合，只要失去过健康，回合结束失去一次幸运；不按健康损失次数重复。
- 针扎人偶：每回合第一次健康损失额外扣一次决心。决心不足转健康不会重复触发自身。
- 溺鬼耗竭：只计当前正被挑战牌上未完成的挑战；咒物在场计咒物，移开后计咒灵。
- 命运机器：玩家选择初始修正后某骰子的当时点数，固定该点数至回合结束，不跟随该骰后续变化。
- 古怪护符：骰池调整阶段支付一次健康后重掷所选非奖励骰，可重复使用；死亡时不再重掷。
- 活肖像画：每回合第一次为属性收益放入职业格时，另弃一颗未使用的普通骰子；没有额外骰子不能执行。仅改点／翻面的选项不触发。
- “失去 A 或 B”“保持或重掷”“能力二选一”等由真人选择；CPU 使用同一合法动作集合。盾牌选择当前一个已揭露能力。

这些裁定须由可重复验证覆盖；文档列出裁定不代表相应实现已经完成。
