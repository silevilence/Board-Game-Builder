# ADR-0002：独立作者层与可替换编辑模式

状态：已采纳，2026-10-10。依据：ROADMAP「CLI 作者工具与可替换编辑模式」。

## 背景

CLI、图形编辑器和直接编写文件都需产出相同的运行工程。复用编辑器内存文档作为独立 CLI 的基础会引入 UI 生命周期与保存语义；直接写磁盘又会绕过图形编辑器草稿和 Undo。

## 决策

- Authoring 仅依赖 Runtime，定义只读 `ProjectView`、`ProjectSource`、`ProjectChanges` 和 `IProjectEditMode`。作者格式改用 `IAuthorFiles`，不依赖 ModuleDocument。Runtime 和 Player 不反向依赖 Authoring 或 Editor。
- 作者宿主使用独立 CordiSharp 根及受信任安装插件目录。作者 profile 完整选择插件，至少包含核心且恰好一个编辑模式；与 `game.start.json` 运行配置分离。领域插件注册操作说明、执行函数及文档贡献，CLI 不为游戏规则添加分支。
- 一次领域操作固定内容快照与来源身份。读取跟踪文件、存在性和枚举依赖；提交核对这些依赖及目标基线。运行、校验和打包使用独立临时快照并返回来源版本。
- 磁盘模式每次重新捕获文件，逐文件替换。持久化请求意图、原内容和回执，区分全部成功、冲突、部分失败与未知；重复输入核对请求标识。跨任意外部进程的多文件提交不承诺全局原子性，恢复只显式向前完成仍匹配基线的部分。
- GUI 模式由 Editor.Core 适配 DocumentWorkspace，修改包含草稿并形成可撤销操作；显式保存才落盘。文件无效、未应用字段、双格式冲突均保留并诊断。外部文件协调要求两份版本，人工完整合并结果可以替换无效草稿。
- Editor 的可选连接插件发布当前用户命名管道及实例发现记录。请求绑定工作区和文档代次；UI 调度后再次检查身份与取消。插件释放撤销发现记录、监听与订阅；连接中断不静默改用磁盘。
- 入口 SKILL 由发行模板渲染绝对 CLI 与文档路径。复制与 Junction 都保存安装归属；维护只处理本安装拥有的文件，Junction 指向独立生成目录。技能仅描述游戏创作，不复制仓库开发规范。

## 后果与边界

共享领域代码可通过两种编辑模式验收，图形控件不成为作者数据的所有者。回执是历史证据，不代表源文件此刻仍相同；删除私有日志或关闭 GUI 后，未知结果不能作为自动重放依据。

本期不提供任意文本的自动三方合并、任意第三方编辑器的原子锁或任意 Agent harness 的链接发现承诺。已验证环境与实际产物见 [验收记录](../validation/cli-author-review.md)。

## 独立导出与可选运行组合补充（2026-10-31）

Authoring 的依赖已扩展为显式作者适配、运行目录及可选构建服务；“仅依赖 Runtime”不再描述完整项目引用。无 UI 的 ProjectView／编辑模式契约保持不变，Runtime、小核心与 Player 不反向引用作者或 Editor。

`author.export.package`、`author.export.player`、`author.export.native` 各自贡献元数据、预检与执行；Editor／CLI 共用 AuthorExports，不在 UI 按产物类型分支。NativeAOT 所需 SDK 与 C++ 工具只由该提供者要求。活动导出持有提供者和运行插件 lease；文档替换、取消或关闭先等待任务退出，再归还资源。失败不发布成功目录，也不降级其他方式。桌游静态应用由 `author.runtime.board-application` 适配，非桌游组合独立注册，缺结构化作者格式仍保留文件编辑与试玩。说明和证据入口见 [原生发布说明](../native-publication.md)。
