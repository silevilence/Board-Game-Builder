# 作者发布参数与运行配置

`game.start.json` 是唯一运行插件选择。Editor 的“运行插件配置”面板分别显示文件中的 ID、版本、API、实现指纹，已安装的元数据，以及当前会话实际捕获的快照版本。外部实现选择写入包指纹。列表也展示作用域、依赖、update/render 回调及先后约束；导入或查看元数据本身不会启用插件。

“启用／使用此版本”和“移除此插件选择”修改入口草稿，可撤销／重做。配置字段在完整 JSON 中修改。新增实现若需要必填配置，草稿可暂时无效；诊断不删除未知内容，不自动迁移旧工程，也不为非桌游工程补入桌游插件。运行中的实例继续使用原快照，须显式重新开始才能采用修改。

发布面板的参数保存在独立 `author.publish.json`，例如：

```json
{
  "format": 1,
  "selected": "native-directory",
  "providers": {
    "game-package": { "target": "C:/games/export/game.bgm" },
    "native-directory": {
      "target": "C:/games/export/native-game",
      "sdk": "C:/bgb/native-sdk",
      "host": "application.desktop",
      "platform": "win-x64"
    }
  }
}
```

它不包含运行插件启用清单，也不会作为游戏运行内容被打包。首次修改导出参数会在内存文档中创建文件；后续输入进入文件草稿。保存才写入源工程，撤销、保存重开及切换文档沿用工作区规则。尚未编辑的界面默认值不自动创建文件。

停用某个导出提供者保留其参数和选择；再次启用后恢复。当前格式保留未知参数，便于作者或插件升级后继续使用；执行时仍按所选提供者的参数契约校验。无效 JSON 保留在配置面板并阻止发布，不从旧磁盘配置回退。CLI 调用使用同一导出提供者的显式操作参数；可通过通用文件操作读取或维护此作者文件。

“校验当前草稿”消费指定工作区代次的 ProjectView，使用与发布相同的作者运行能力。面板重建不会丢草稿；切换文档会取消校验，迟到结果不写入新文档。缺少作者格式时仍有通用文件编辑、运行插件配置和已获准的应用试玩。
