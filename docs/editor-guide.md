# 编辑器操作（M2.5）

维护者构建：`dotnet build BoardGameBuilder.slnx -c Release`。
运行 `src/Editor/bin/Release/net10.0-windows/Editor.exe`，或用目录路径作为启动参数。
作者使用预编译编辑器；制作游戏和导出过程不会生成 C# 工程或调用 SDK。

## 文档和制作

- 新建空模块，填写一个尚不存在的模块目录并保存；打开已有目录时读取 `module.json`。
- 模块配置页编辑 JSON 后点“应用配置草稿”；撤销、重做和保存覆盖所有已应用的作者修改。
  草稿在其他面板修改时保留；同一配置发生冲突时会拒绝应用，请复制草稿、重新读取并合并。
  保存检测到磁盘外部改动时不会覆盖，可另存新目录或重开后合并。
- 官方插件提供资源树、原型与实例、媒介组件、席位与阶段、Lua 脚本及布局视口。
  停用插件会释放这些页，文档、草稿、撤销历史及试玩由基础插件持有；重启插件会读取当前文档。
- 原型与实例 页可创建原型、从原型实例化实体、读取组件并应用字段覆盖。
  原型更新传播到未覆盖字段；数组整体覆盖，不按索引合并。移除实例覆盖恢复继承。
  独立的模块 YAML 页读写与 `module.json` 等价的数据；磁盘主配置仍是 `module.json`。
- 媒介组件页提供字段表单；先选择实体、组件，再读取或添加组件。
  实例只覆盖实际修改的字段，未修改字段继续随原型更新。
  `container` 的 `ordered=true` 可作为牌库/堆叠，`contents` 每行一个实体标识；
  手牌加 `owner` 和 `visibility=owner`，牌库内容可设 `hidden`，公开区域用 `public`。
  `faces` 配多面名称、资源、初始面与朝向；`properties` 配数值。
- `dice.values` 每行一个整数，并在 `properties.value` 配有效初值；
  `counter` 的 property/min/max 约束同名属性，初值放在 `properties`。
  错误引用、容量、可见性或数值范围会在校验、保存或试玩时明确报错。
- 布局视口显示作者初始局面，可拖动对象。方格为列/行，六角为轴向 q/r，
  自由布局为像素坐标；拖动和运行时移动使用共享吸附计算。未声明布局的旧卡牌模块保留自动排布。

## 试玩与调试

试玩页选种子，各席位勾选 CPU，未勾选的为真人。默认一名真人，其余 CPU。
进程内试玩使用独立 `PlaySession`，停止不写回初始局面。
独立模式填写维护者构建的实际 `Player.exe` 路径，勾“独立 Player”；
Player 单独显示同一投影，调试命令和操作从编辑器发出。两者共用协议和运行时。
本机调试通过父子进程标准管道通信，没有游戏网络服务。

暂停会在命令边界生效；单步 CPU 执行一次提议（其原子规则派生命令一起提交）。
时间轴默认显示玩家可读记录；勾选作者日志才显示命令内容与 CPU 诊断。
选择席位并点“切换观察身份”查看其投影；全信息调试须额外勾选并带明确标记。
这不改变规则或 CPU 的查询身份。正式 Player 构建没有调试入口。

Lua 页直接编辑规则/CPU，修改加入文档脏状态与撤销历史。点击热重载时校验两份脚本，
成功后从下一条命令生效；失败保留当前会话的旧版本。
实体、资源、席位、阶段、依赖变化必须重开。运行时错误包含脚本路径、入口与 Lua 行号。
保存调试日志保留全部脚本版本和切换边界，打开重放使用已记录的结果，不重新运行 CPU。
回放期间禁止提交、单步和热重载；点击“继续”返回原试玩会话。
作者日志包含私有数据，不能作为玩家日志分发。

## 导出和验收

维护者执行 `scripts/publish-player.ps1 -Output <新目录>` 构建官方自包含发行物。
编辑器独立导出页填发行目录与新目标目录，先预检，再保存并导出。
双击产物中的 `Play.exe`；无需编辑器、.NET SDK 或另装运行时。
该入口是 Windows GUI 可执行文件，Lua 子进程隐藏创建，不经 `.cmd` 启动。
插件导出附加步骤只使用当前启用注册；失败不会留下最终输出目录。

支持 Windows x64 / Direct3D 11。暂未验收其他系统；原生视口仍有 HWND airspace 限制。
全 CPU 批量、实际两种试玩和导出的复现命令见 [M2 验收记录](validation/m2-review.md)。

## 插件管理

插件管理页显示依赖状态和失败原因。必需的文档、会话、命令、视口服务、
工作区、程序集装载、设置及管理插件仅随应用退出释放；可选作者面板可单独启停或重载。
停用试玩面板不会停止对局，恢复后连接同一会话。关闭应用仍会询问未保存修改并停止会话。
模块 JSON/YAML 草稿和 Lua 修改不依附可视控件，面板重建后仍可继续编辑与撤销。
导出进行中拒绝停用导出插件及其附加步骤所有者，也拒绝退出，待完成后再操作。

可信预编译扩展在管理页填写 DLL 路径，旁边需要同名 `.plugin.json`。
“停用”移除功能，“重载”重建实例，“卸载程序集”还会检查真实加载上下文回收；
残留引用会明确报错。插件开发及状态归属见 [开发说明](editor-plugins.md)。
本轮版本和自动验证入口见 [M2.5 接入记录](validation/m25-integration.md)。

未应用的席位/阶段、组件 YAML、媒介字段也由文档保留，包括尚不能解析的输入。
关闭时“取消”保留全部草稿；保存或试玩会提示先在原面板应用或放弃字段。
“放弃所有字段草稿”可清除已删除对象或已关闭面板遗留的输入；不会清除已应用修改的文档撤销历史。
其他面板修改过配置后，旧字段草稿拒绝覆盖，须读取最新内容再合并。
