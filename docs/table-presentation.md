# 数据驱动的桌面呈现

以下整数属性放在实体的 `properties` 组件中，由共享 `TableScene` 和 MonoGame 视图解释。它们只改变呈现，不赋予命令权限；规则与 CPU 仍使用各自的 `SeatView`。群岛开拓模块提供完整实例。

## 自由棋子与信息面板

| 属性 | 语义 |
| --- | --- |
| `viewStyle` | 1：图片／标签；2：连接线；3：信息面板。未声明时沿用原有棋子呈现。适用于未放入容器的非容器实体。 |
| `viewWidth`、`viewHeight` | 以实体世界坐标为中心的呈现与命中范围，4～2000。连接线的命中范围独立于线段长度。 |
| `viewLayer` | 从小到大绘制；同层保持原有次序，命中优先选择最后绘制的可交互对象。 |
| `viewColor` | `0xRRGGBB` 对应的十进制整数，用于文字、线条或面板标识。图片保留原色。 |
| `viewLabel` | 1 显示当前面的名称，否则不显示文字；名称中的 `{属性名}` 替换为本投影内该实体的整数属性。 |
| `viewLabelY` | 图片标签相对实体中心的纵向偏移；默认位于图片下方。信息面板按左上方排版并支持名称中的换行。 |
| `viewLineX`、`viewLineY` | 连接线两个端点的像素差，线段中点位于实体中心；各轴限制在 -4000～4000。 |
| `viewPassive` | 1 时只绘制、不参与选中／命中，适合地形装饰。 |
| `viewNoImage` | 1 时不使用当前面图片，保留标签；可由规则的 `set` 命令改变。 |

图片仍来自 `faces.resources`，不会从未投影的实体加载图片。切换面、计数与位置均使用原有命令。示例中的村庄、城市、地形和道路没有新增 Kernel 玩法组件。

存在这类图片时，视口首次按内容适应窗口；滚轮缩放或平移后尊重用户相机设置。容器的牌尺寸、扇形叠放，以及 `viewTheme=1` 经典纸牌桌面沿用原有视觉行为。`viewTheme` 不决定 Player 外壳、自动开局、动作栏显隐或会话模式。

## Player 外壳与展示信息

`Player.exe gui <模块目录或包> [--shell game|tools]`：显式模块路径或可执行文件旁存在 `game.bgm` 时默认 `game`，直接按模块席位配置开始对局，仅保留通用菜单和游戏所需操作。没有模块参数且没有捆绑模块时默认 `tools`，保留加载工具栏并等待开局。两者都能从文件菜单切换工具栏；切换不重开当前对局。显式 `--shell` 优先于默认选择，与 `viewTheme` 无关。

游戏菜单的开局设置（F3）可调整种子、本地模式及每个席位的真人／CPU；确认才创建新对局，取消不改变会话。至少一个真人；单人模式恰好一个真人。未指定真人的模块在 GUI 中默认选择首席位，其余交给 CPU。全 CPU 批处理继续使用 CLI `batch`。

模块可在 `resources` 注册保留键 `"player.presentation": "player.json"`，内容为 UTF-8 JSON：

```json
{
  "title": "我的桌游",
  "help": "游戏规则和操作说明。",
  "showActions": true
}
```

这是 Player 专用展示资源，复用现有资源打包、哈希及快照传输；不进入规则状态，不要求 Kernel 理解 UI。内容为纯文本，大小上限 32 KiB；标题上限 120 字符，帮助上限 12000 字符，未知字段／错误类型会使 Player 加载失败并显示恢复入口。缺省标题使用模块 ID、帮助使用通用操作说明、动作栏默认显示。配置变更会改变模块指纹，旧日志仍应使用其原模块／快照回放。

空当接龙通过自己的 `player.json` 指定标题、规则帮助和隐藏动作栏；经典主题只保留视觉语义。群岛用同一宿主菜单和开局设置，默认显示合法动作。可通过查看菜单随时恢复隐藏动作栏，热座交接和控制席位提示始终保留。

## 示例

```json
{"type":"faces","data":{"names":["港口成交\n{wasm.counter} 次"],"resources":[],"up":true}}
```

配合 `viewStyle=3`、`viewLabel=1` 和受限 WASM counter 组件，可以直接显示更新后的成交次数。模板只读取当前实体的投影属性，不支持脚本执行、跨实体查询或隐藏状态访问。
