# V0.5.0 全范围审核与修复

审核日期：2026-11-02。固定基线为 `fb8418e55e072369a59d54838da20e0a04a8db64`，本轮实现截至 `724633f`，共 28 个提交、613 个变更文件（包含研究、截图及验收数据）。审核覆盖整个 NativeAOT／可选渲染后端／外部运行插件任务、V0.5.0 的实际发行路径，以及下列修复。修复后的代码由 V0.5.0 标签锁定，正式产物由该标签的发布工作流生成；本地候选仅作验证，不直接上传。

## Standards：结构、规范与生命周期

独立审核覆盖插件导入、安装完整性、共享契约、版本占用、静态工厂、依赖闭包、工具链、原生构建、运行期完整性、Editor 草稿代次及取消、GL 资源所有权、两份第三方补丁，以及状态／WASM 编解码。

实现继续采用 MonoGame，补丁固定上游提交和内容身份；Editor 能力由所属 CordiSharp 插件贡献；共享运行层不依赖 Editor。未发现需要替换既定架构或扩张本轮范围的问题。疑似视口先于宿主释放问题经核对 RuntimeHost 子上下文先释放的实现后不成立，不作无证据改写。

## 验证记录

- 全解决方案 Release 构建：零警告、零错误；项目依赖边界检查通过。
- 25 个项目的基础回归最终全部通过，其中 Engine.Tests 的 125 个默认组全部通过，包含 72 组入口语义比较、60 局多席位批量对局、作者／联机／隔离／资源与输出检查。Motion 和两个渲染后端及真实游戏的四个图形套件全部通过，设备、后端和原生窗口释放检查为零。
- 发布脚本 51 项 Python 测试通过，包含原生能力清单校验和缺件／篡改／错误目标／重复路径失败场景。
- 实际 standalone／slim 工具包均通过版本、三种图形入口、两处 SDK、导出、CPU 对局、完整性及压缩布局校验。自包含 CLI 不指定 `sdk` 路径，直接使用随包 SDK 成功导出原生游戏。
- 自包含发布闭包测试通过；普通导入的 26 项检查通过；静态 CordiSharp 下的 Native.Board.Tests 完成固定种子、恢复续局、格式 1 兼容及篡改拒绝。
- Authoring.Native.Tests 使用本轮随包 SDK，通过工具链拒绝、精确后端身份、活动提供者保护、编译取消、重试、未保存草稿导出与源工程不变检查。最终产物的 ILLink／ILC 警告视为错误，`strictWarnings=true`。
- 严格 NativeAOT 席位探针在已启用 GPU、未安装系统 .NET 的同一 Sandbox 中运行，热座／单人加 CPU／全 CPU 各 5 次，合计 15 次启动与重开，全部完成真实绘制、记录验证及等待关闭；最终原生子窗口数量为零。
- 最终代码的无脚本／WASM／外部 CPU／WASM＋外部 CPU 各完成 5 次原生对局，共 20 次；普通窗口各重跑 2 次。四个组合的记录文件 SHA-256 逐字节一致，见 `comparison.json`，包含隐私、暂停、完整对局、重开、保存中关闭和释放检查。
- 使用压缩布局工具包内的 SDK 构建正式 WASM＋外部 CPU 游戏，严格编译通过；在沙盒手动完成洗牌、抽牌、WASM 加二、CPU 完局、保存并校验回放，权威终态与探针一致。正常退出后 Play／探针剩余进程数为零。
- 固定 CordiSharp 编译路径映射后重建 SDK，再次严格构建上述正式组合并在沙盒完成同样对局与回放。第二份正式产物的权威终态仍一致，见 `combined-mapped-release.json`、`v050-mapped-comparison.log`。
- 从本轮 SDK 导出的正式 Motion 程序在上述沙盒中显示中文草稿并正常退出；未安装系统 .NET 或引擎源码。本次短按键未获得可区分的前后截图，不单独作为输入通过证据；持续方向输入、复位和多视口行为由 Motion.ViewTests 覆盖。

首次测试的两项环境配置错误已保留：隔离构建测试读取了源目录中的旧 0.4 插件夹具，重建匹配的 0.5 夹具后通过；Native.Board.Tests 默认启用裁剪且关闭 JSON 反射，必须按既定约定使用 `UseStaticRuntime=true`，按该配置重跑通过。不得把这两次失败记录为成功运行。

全量回归还修正了一项测试假设：ResourcePluginTests 曾将全部示例交给桌游 LoadedModule 解析器，遇到泛用 Motion 应用时错误失败。现在依据获准目录的 `definition` 能力选择桌游快照用例，未知附加插件仍正常拒绝；泛用应用的资源／包往返继续由 Motion.Tests 验证，没有给运行时增加任何回退。

并行原生构建期间，Engine.Tests 的 latency 组超过本机 1000 ms 预算；停止并行编译后以独立进程复测通过，8 次真人＋CPU 交互最大 313.1 ms。首轮超时与复测日志均保留，不将该失败静默跳过。

## 支持范围

本轮交付 Windows x64、已验证的 OpenGL 图形会话。Lua 原生路径仍明确不支持，继续使用普通 Player；WindowsDX 普通运行保留。NativeAOT 构建机需要固定 .NET SDK 和 C++／Windows SDK，玩家无需系统 .NET。不把虚拟机单次启动测量解释为稳定性能收益，也不以声明兼容代替任意外部插件的真实严格编译。

审核结论：六项已确认问题均已修复，另修正一项测试的领域范围假设；无剩余已知审核阻塞。可以进入 V0.5.0 标签发布，公开发行状态以 GitHub Release 及其工作流结果为准。
