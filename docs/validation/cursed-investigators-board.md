# 咒物调查员：牌桌直接操作验收

2026-10-17，基线 `7373489`。对应 ROADMAP「改为牌桌内直接操作，移除操作栏」。保留已确认的标准单人、战役和初学者范围。

## 实现

- 取消本 sample 的右侧操作栏和底部动作列表。标题、模式、人物、职业的分步开局不变，终局通过牌桌按钮返回新标题。
- 点击咒物调查，点击骰子选择；普通骰子选中后显示改点按钮，可点击职业牌上的能力格保留。挑战区按咒物／咒灵实际牌面位置显示合法点击区域，奖励可用时直接点左下的奖励牌。重掷、取消选择、确认保留、结束回合放在骰池附近。
- 多种支付方式、职业效果和阶段奖励使用牌桌内的局部菜单，每页六项，支持翻页、点背景、关闭按钮及 Esc。菜单导航不提交规则命令，也不改变骰子选择。
- `BoardActions` 仅消费当前席位投影和已有合法动作；模块配置匹配种类、参数与锚点，不能创建命令或读取隐藏状态。提交仍经当前 `PlayerSession` 版本与合法动作校验。新投影清除旧点击状态，动画与提交期间锁定输入。
- 引擎不含 sample 名称、实体名或规则判断。布局、提示与挑战区位置均在 sample 内；游戏逻辑只增加必要的展示更新，并在咒物奖励已可用时显示其牌面。捕获与日志条件不变。没有新增 CLI 功能或编辑器功能。

## 修复与审核

发布 CLI 首次校验发现展示锚点不允许空牌面名称，修正作者数据后重新写入并校验。规则测试发现新增展示命令使一个结算分支达到 65 条、超过 64 条预算，改为固定点击区域尺寸，去掉重复尺寸更新；不放宽引擎预算，九组重新通过。图形探针曾把日志的参考页按钮误认为动作栏，改为检查合法动作按钮后通过。

最后核对引擎／游戏边界、合法动作来源、菜单与权威状态分离、隐藏投影、固定画布、动画输入、旧配置兼容和关闭／重开释放。原图、字体、许可证未修改。验收通过后原地勾选并本地提交，不推送。
