# 资源加载插件验收记录

日期：2026-10-08。范围对应 ROADMAP「资源加载插件与统一资源池补充」。

## 实现

- `resources` 管理唯一资源服务和原始文件；`resources.images` 与 `resources.texturepacker` 按显式配置登记加载器。注册属于 CordiSharp effect，加载结果冻结为可序列化资源池。
- 两种图片加载插件均支持单文件、目录加 `*`／`?`／`**` 筛选、整目录递归扫描、命名前缀。整目录默认按格式扩展名选取，配套图片／许可文件不会被当作图集；显式筛选匹配不支持的内容时报错。
- 单图和图集转换为统一命名图片描述。视图、Player、编辑器与打印消费资源池；TexturePacker 解析仅位于 Runtime 的资源插件，GPU 纹理仍归视口管理。
- FreeCell、群岛及扑克牌 UNO 的资源声明、生成脚本与说明均迁移。编辑器图片／TTS 导入同时更新资源、定义和启动配置，已有目录规则能发现导入图片时不重复登记，Undo 恢复全部内容。
