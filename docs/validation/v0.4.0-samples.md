# V0.4.0 示例发行验收

日期：2026-10-29。平台：Windows x64，Release 构建，产品程序集版本 0.4.0.0。

全部 12 个游戏入口已验证。11 个桌游在目录与数据包两种加载方式下跑至终局，录制重放的权威状态及各席位投影一致；包含 UNO 4／5／6 人预设，共 13 个场景。FreeCell 使用 seed 1 的 94 步合法通关路径，其余脚本示例使用 CPU，静态命令示例执行合法动作。实时示例 motion-lab 验证持续更新、方向键输入与到达目标。

图形验收逐个打开 12 个目录和 12 个包，共 24 个窗口，检查绘制帧、开局导航、合法操作及关闭后的设备／后端／原生窗口归零。咒物调查员经过标题与职业选择；群岛开拓经过本地席位交接。另核查了咒物调查员、群岛开拓的实际截图。机器可读结果见 [v0.4.0-samples.json](v0.4.0-samples.json)。

发行准备同时通过：解决方案 Release 构建（零警告／零错误）、项目依赖边界、正式导出与依赖解析回归、原生入口两次重新链接哈希一致，以及 46 项 Python 发行测试。产品版号由 `Directory.Build.props` 的 `Version=0.4.0` 统一提供；独立启动器保持 0.1.0，游戏身份、插件协议、第三方依赖版本不随产品版号变更。

本轮补齐咒物调查员工程生成脚本的显式渲染插件声明，并增加生成回归测试；更新旧示例运行路径。最小 Player 验收在关闭事件后等待 Avalonia 延迟销毁原生子窗口，避免将尚未完成的销毁误报为泄漏。

主要复现命令（仓库根目录）：

```powershell
dotnet build BoardGameBuilder.slnx -c Release
dotnet run --project tests/Engine.Tests -c Release -- samples-release author-cli tts-import export-dependencies system-runtime author-exports
dotnet run --project tests/Player.Hosting.Tests -c Release -- --samples .scratch/samples-gui/report.json
dotnet run --project tests/Motion.Tests -c Release
dotnet run --project tests/Motion.Authoring.Tests -c Release
python -m unittest discover -s scripts/tests -v
./scripts/check-boundaries.ps1
```
