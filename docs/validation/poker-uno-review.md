# 扑克牌 UNO 展示验证记录

日期：2026-10-08。对应 ROADMAP「扑克牌 UNO：M4 完成后的总体功能展示」。

实现及本机验收已完成；跨机联机和干净 Windows 人工验收未执行，保留两个顶层验收任务未勾选。没有以本机多进程或隔离 .NET 搜索路径代替这两个门槛。使用方式见 [扑克牌 UNO](../poker-uno.md)。

## 交付与边界

- `samples/poker-uno`：52 张普通扑克牌，4／5／6 人预设，规则与 CPU 均在 Lua 中。摸牌后仅能打出新摸到的牌或结束回合；耗尽时保留当前弃牌、隐藏回收其余弃牌并洗牌；连续整轮无牌可出且无牌可摸时平局。
- 通用引擎补充：PNG 区域引用 `resource#x,y,width,height`、定义文件预设、隐藏抽取、水平扇形布局和只显示堆顶；没有游戏名称或牌点数的宿主分支。
- 图形 Player 增加任意席位与全 CPU 设置、联机加入／恢复、公共观战及身份记录。联机只提交操作和消费投影，规则和 CPU 留在权威服务器。
- 协议版本升至 2：实际席位控制方式随帧作为独立元数据传递，不修改规则投影；旧协议客户端被明确拒绝，记录读取器仍兼容协议 1 的历史记录。
- Player 可依赖 Networking；Runtime 仍不依赖 Editor、Editor.Core 或 Avalonia 插件，服务器不依赖图形窗口。作者格式和打印沿用原有 CordiSharp 插件服务。
- 本地发行物：`artifacts/poker-uno/windows/Play.exe`、`game.bgm`；独立服务器：`artifacts/poker-uno/network-release/Server/Server.exe`。验证结果、截图、发行文件和测试凭据留在 Git 忽略的 `artifacts/poker-uno/`，不提交密钥。

## M0～M4 能力覆盖

| 阶段 | 本示例入口与实际覆盖 | 限制／补充入口 |
| --- | --- | --- |
| M0 | Lua 规则、命令原子拒绝、隐藏投影、受控随机、CPU、整局与回放；规则测试及 60 种子批跑 | CPU 采用简单同花色保留策略，不宣称最优 |
| M1 | MonoGame 桌面、点选／拖拽合法牌、动作按钮、牌面、牌背、缩放适应；单图集共享纹理 | 图像 PNG 区域引用；不增加任意格式图集解析器 |
| M2 | 作者打开／修改／保存／重开、Undo／Redo、两种试玩、暂停／单步、身份观察、安全重载、记录；预编译 Player 导出 | 通过作者工作流展示，不为玩家增加调试操作；干净 Windows 尚待人工验收 |
| M2.5 | 复用现有 CordiSharp 编辑器贡献与作者格式，打印按图集区域裁切 | 未另建编辑器面板体系；插件生命周期由既有回归补充 |
| M3 | 4～6 人热座交接、同屏多投影、任意 CPU、全 CPU 观战；打印输出 | 不向基础玩法加入秘密提交、同时行动、拍卖或 WASM；由密封拍卖、WASM 示例及对应回归补充；图片／TTS 导入仅回归既有测试 |
