# M3 本地交互与扩展验收

日期：2026-10-07。依据 ROADMAP 的 M3 九项任务；逐项验证与整体审核记录于此。

## 本地热座与同屏

Player 顶部选择本地热座／同屏分视角，输入逗号分隔的真人席位；其余由 CPU 控制。
交接会清除场景、选择、动作与原生视口，下一席位确认接手后重新创建。
同屏分别投影；身份与修订号在 Runtime 校验，不从 UI 输入推断授权。
同屏的物理旁观限制在界面显示。作者调试仍通过原有显式观察身份入口操作。

验证：Release 解决方案构建 0 警告／0 错误；`local-table interaction` 通过。
覆盖双真人／真人 CPU、两种展示模式终局、遮蔽帧、他席位与旧帧拒绝。
真实窗口 `artifacts/m3/local-reviewed.json` 通过快牌／密封拍卖 × 热座／同屏 × 全真人／混合 CPU
共 8 个场景，均有实际渲染并完成对局；交接遮蔽时没有视口，关闭后图形设备计数归零。

## 同时行动与秘密提交

Lua 通过 `secret-open` 声明参与席位、数值范围、可修改性、逻辑收集步数、
缺席弃权／默认值、全体锁定或关闭后揭示。提交、弃权、锁定、逻辑时钟推进、
关闭、揭示及结算均走原子命令与记录；普通投影只包含本人的选择和公开进度。
该收集期使用逻辑步数，真实时间截止属于后续权威会话的策略。

`secrets local-table replay visibility` 通过：非当前参与席位同时提交、修改／锁定边界、
提前揭示与重复结算拒绝、截止缺席处理、真人 + CPU 完整一轮以及记录重放一致。

## Lua 密封拍卖

`samples/sealed-auction` 提供三席位出价、弃权、逻辑截止、揭示、席位顺序平局规则和结算。
规则全部在 Lua，CPU 只从席位投影与合法出价动作选择。`auction` 验证真人 + CPU 与全 CPU
各 20 个固定种子、隐藏值隔离与回放；另覆盖同价、越界出价、全部未提交及重复结算。

## WASM 加载

固定 Wasmtime 48.0.2；`wasm packages replay` 通过。真实 WASM 在 PlaySession 与
Editor 使用的 DebugSession 中加载；错误版本、哈希、权限、第三方原生依赖、
缺失文件均失败；数据包往返保留指纹，运行时插件变更必须重开会话。

## WASM 媒介扩展

`wasm-extensions` 通过计数器三步终局、标准效果回放、数据包往返、整数吸附和隐藏目标拒绝。
`samples/wasm-counter` 可在配置及 Lua 使用扩展；可选 `author.extensions` 面板管理组件草稿。
正式 Player 已自包含发布到 `artifacts/m3/player-release-final`，由其导出到 `wasm-export-final`。
`artifacts/m3/wasm-gui-final.json` 记录该导出真实窗口的两局终局，最终属性为 3，无编辑器依赖。
预检会拒绝缺少 Wasmtime 托管／原生依赖的旧发行目录。

## WASM 隔离与限制

`wasm-isolation` 使用真实二进制覆盖 WASI 文件访问、伪造隐藏真值 host import、
初始化死循环／异常、初始内存超额、运行时 memory.grow 超额、线性内存越界及无权注册。
命令中的死循环／异常／超范围返回均拒绝且权威哈希不变、效果日志为空；随后正常插件仍可执行。
同一模块最多 32 个插件，每个实例受 fuel／内存／表限制。此接口无状态内存句柄。

## 图片、桌布与切分导入

`image-import` 覆盖 2×2 切分成牌组、命名冲突、无效尺寸、陈旧预览拒绝、单步 Undo/Redo、
保存重开及数据包资源完整；桌布成为不参与命中测试的背景。
`Editor --verify-m3 artifacts/m3/editor-images.json` 在真实编辑器连续三轮启停图片插件，
重建后草稿恢复、预览／应用／撤销及入口注销均通过；截图保存同名 `.png`。
该入口同时确认禁用 WASM 配套 UI 后计数器仍可终局。

## TTS 子集转换

已固定用户确认的 `samples/tts-subset/save.json` 合成样例。`tts-import` 通过牌堆顺序、
卡图切分、posX／posZ 映射、桌布、原始输入逐字节保留、命名冲突、Undo 与保存重开。
不支持对象、未转换字段及远程／缺失图片出现在预览报告中，Lua 原样留档不执行。
`artifacts/m3/editor-tts.json` 通过真实 TTS 面板三轮重建、转换、撤销与命令注销。

## 打印拼版与 PDF

`print` 验证 A4、63×88 mm、10 mm 页边距、7 张卡的 4 页正反面排布，
长边／短边翻页配对以及无效尺寸和现有文件拒绝。预览与 PDF 使用相同毫米矩形。
Poppler `pdfinfo` 确认 4 页、595.276×841.89 pt、PDF 1.4；4 页逐页渲染并检查正反面镜像位置。
`artifacts/m3/editor-print.json` 通过真实打印面板三轮草稿恢复、预览、导出和入口注销。
仅编辑器包含打印实现，Player 不依赖 System.Drawing 打印代码；不支持未定义的 lam 格式。
纸质打印机未连接；文件按实际尺寸 / 100% 打印，翻页方式须与面板所选相符。

## 整体审核与回归

审核范围为基线 `cddeb9fbc6a318415d1d07c3305a4534c75ab5a3` 后的 M3 修改。
两个独立审核代理分别检查仓库规范与 ROADMAP 验收，修复后再次复核，均确认无剩余阻塞。

### Standards

确认 1 项规范问题（P2）：图片／TTS 预览后修改字段仍应用旧结果并消耗新草稿，
违反 editor-cordis 的持久草稿归属要求。现在同时绑定文档实例、文档修订及字段快照，拒绝时保留草稿。
另有 1 项判断性风险：本地多人在 UI 线程执行 Lua 读帧可能阻塞窗口。
会话创建与读帧现已移至后台，迟到创建的会话会释放。
复核结论：两项均解决，无剩余阻塞。

### Spec

确认 3 项问题：主持席位已锁定时无法推进缺席截止（P1）、截止后独立锁定仍被接受（P2）、
同屏非当前参与席位无法同时提交（P2）。最后一步提交与锁定现可原子完成，
截止后另发锁定会拒绝，记录重放采用同样的批次语义；同屏按各自席位查询动作，热座可遮蔽后交还主持。
另处理资源预算建议：图片和 TTS 输出逐图累计检查 64 MiB 限额，TTS 在读取前检查存档大小。
复核结论：三项均解决，相关五组测试由审核代理独立重跑通过，无剩余阻塞。

### 最终验证

最终 Release 解决方案构建为 0 警告、0 错误；`scripts/check-boundaries.ps1` 通过。
`dotnet tests/Engine.Tests/bin/Release/net10.0/Engine.Tests.dll` 默认全量 40 组全部通过，
完整输出在 `artifacts/m3/regression-final.log`，包含旧单人／CPU／回放／两种试玩模式和全部 M3 测试。

`Editor --verify-m3 artifacts/m3/editor-reviewed.json` 在真实编辑器完成每类面板 3 轮
启停／重建／操作／注销，额外验证修改预览字段后拒绝应用并保留草稿；WASM 无配套 UI 仍可运行。
相关测试覆盖独立逾期锁定拒绝、最终原子锁定和回放、缺席时已锁定主持推进、同屏同时行动。
物理打印和新建干净 Windows 环境未在本轮验证；正式自包含产物在当前 Windows 主机验证。

审核计数：Standards 为 1 项规范问题和 1 项判断性风险，原最高 P2；Spec 为 3 项确认问题，原最高 P1；修复后两轴均无待办问题。
