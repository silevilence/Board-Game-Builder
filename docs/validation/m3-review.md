# M3 本地交互与扩展验收

日期：2026-10-07。依据 ROADMAP 的 M3 九项任务；逐项验证与整体审核记录于此。

## 本地热座与同屏

Player 顶部选择本地热座／同屏分视角，输入逗号分隔的真人席位；其余由 CPU 控制。
交接会清除场景、选择、动作与原生视口，下一席位确认接手后重新创建。
同屏分别投影；身份与修订号在 Runtime 校验，不从 UI 输入推断授权。
同屏的物理旁观限制在界面显示。作者调试仍通过原有显式观察身份入口操作。

验证：Release 解决方案构建 0 警告／0 错误；`local-table interaction` 通过。
覆盖双真人／真人 CPU、两种展示模式终局、遮蔽帧、他席位与旧帧拒绝。
真实窗口与全量回归留到最终整体验证。

## 同时行动与秘密提交

Lua 通过 `secret-open` 声明参与席位、数值范围、可修改性、逻辑收集步数、
缺席弃权／默认值、全体锁定或关闭后揭示。提交、弃权、锁定、逻辑时钟推进、
关闭、揭示及结算均走原子命令与记录；普通投影只包含本人的选择和公开进度。
该收集期使用逻辑步数，真实时间截止属于后续权威会话的策略。

`secrets local-table replay visibility` 通过：非当前参与席位同时提交、修改／锁定边界、
提前揭示与重复结算拒绝、截止缺席处理、真人 + CPU 完整一轮以及记录重放一致。

## Lua 密封拍卖

`samples/sealed-auction` 提供三席位出价、弃权、逻辑截止、揭示、席位顺序平局规则和结算。
规则全部在 Lua，CPU 只从席位投影与合法出价动作选择。`auction` 验证真人 + CPU 与全 CPU
各 20 个固定种子、隐藏值隔离与回放；另覆盖同价、越界出价、全部未提交及重复结算。

## WASM 加载

固定 Wasmtime 48.0.2；`wasm packages replay` 通过。真实 WASM 在 PlaySession 与
Editor 使用的 DebugSession 中加载；错误版本、哈希、权限、第三方原生依赖、
缺失文件均失败；数据包往返保留指纹，运行时插件变更必须重开会话。

## WASM 媒介扩展

`wasm-extensions` 通过计数器三步终局、标准效果回放、数据包往返、整数吸附和隐藏目标拒绝。
`samples/wasm-counter` 可在配置及 Lua 使用扩展；可选 `author.extensions` 面板管理组件草稿。
正式 Player 已自包含发布到 `artifacts/m3/player-release`，由其导出到 `wasm-export`。
`artifacts/m3/wasm-gui.json` 记录该导出真实窗口的两局终局，最终属性为 3，无编辑器依赖。

## WASM 隔离与限制

`wasm-isolation` 使用真实二进制覆盖 WASI 文件访问、伪造隐藏真值 host import、
初始化死循环／异常、初始内存超额、运行时 memory.grow 超额、线性内存越界及无权注册。
命令中的死循环／异常／超范围返回均拒绝且权威哈希不变、效果日志为空；随后正常插件仍可执行。
同一模块最多 32 个插件，每个实例受 fuel／内存／表限制。此接口无状态内存句柄。

## 图片、桌布与切分导入

`image-import` 覆盖 2×2 切分成牌组、命名冲突、无效尺寸、陈旧预览拒绝、单步 Undo/Redo、
保存重开及数据包资源完整；桌布成为不参与命中测试的背景。
`Editor --verify-m3 artifacts/m3/editor-images.json` 在真实编辑器连续三轮启停图片插件，
重建后草稿恢复、预览／应用／撤销及入口注销均通过；截图保存同名 `.png`。
该入口同时确认禁用 WASM 配套 UI 后计数器仍可终局。

## TTS 子集转换

已固定用户确认的 `samples/tts-subset/save.json` 合成样例。`tts-import` 通过牌堆顺序、
卡图切分、posX／posZ 映射、桌布、原始输入逐字节保留、命名冲突、Undo 与保存重开。
不支持对象、未转换字段及远程／缺失图片出现在预览报告中，Lua 原样留档不执行。
`artifacts/m3/editor-tts.json` 通过真实 TTS 面板三轮重建、转换、撤销与命令注销。
