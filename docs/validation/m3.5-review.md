## Standards 审核

独立子代理只读审核发现两项硬问题、一项维护性建议。

1. 打印面板未使用格式保护，打开第二格式会访问不存在的作者接口。已纳入 FormatPanel，并在真实窗口中覆盖默认／第二格式与打印启停。
2. FormatPanel 丢弃异步刷新任务，卸载后可能继续更新 UI。已将等待任务纳入 CordiSharp async effect，等待后及 UI dispatch 内重新检查取消，子面板 IDisposable 也归属子上下文；快速切换和立即停用探针通过。
3. 可能的 Repeated Switches：内置 Lua／WASM 配置分派在启动适配器和两个加载器间有重复。保留为维护性建议；当前获准目录是封闭的静态组合，未新增第三方动态发现，不影响本阶段可替换性验收。

额外移除基线 Player CLI 中 score-/hand- 的游戏展示约定，改为通用投影实体／属性显示。
