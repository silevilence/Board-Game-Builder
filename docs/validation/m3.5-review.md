# M3.5 实施与验证记录

2026-10-08 开始。完整阶段尚未验收；以 ROADMAP 原位勾选为准。

## 契约、宿主与依赖

- 已形成公共契约及兼容矩阵，见 [运行时协议](../runtime-plugins.md)。
- `runtime-host` 验证三轮创建／销毁、两个并存根的服务隔离、关闭其中一个不影响另一个。
- 覆盖缺失必需能力、缺失依赖、循环、重复身份／能力、错误版本、未获准实现、依赖链中途抛错和未提供声明服务。
- 失败后资源计数回到零；重复／并发关闭可等待同一清理；关闭后的迟到注册拒绝并释放资源。
- 初步构建使用本机 SDK 10.0.301 的显式 MSBuild 入口，仓库仍锁定 10.0.112。运行时固定 CordiSharp 0.2.0，不引用编辑器。
